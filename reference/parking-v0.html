parking-v0

Numbers to look up, not to memorize from a blog. Confirm against highway-env source if a claim would change a plot.

Loop

obs, info = env.reset(seed=…)
obs, reward, terminated, truncated, info = env.step(action)
# reset when terminated or truncated

Observation

Type KinematicsGoal. Dict of three length-6 vectors, features in this order:

iFeatureScaleStored value
0x100meters / 100
1y100meters / 100
2vx5(m/s) / 5
3vy5(m/s) / 5
4cos_h1heading unit-x
5sin_h1heading unit-y

observation == achieved_goal (ego). desired_goal is the stall landmark. Heading 0 faces +x.

Action

Box(-1, 1, (2,), float32) then mapped:

IndexNamePhysical
0acceleration[-5, 5] m/s²
1steering[−π/4, π/4] rad

Time

ConfigDefault
policy_frequency5 Hz (0.2 s per action)
simulation_frequency15 Hz (3 physics substeps)
duration100 s → 500 actions if no crash/success

terminated: crash or success. truncated: time >= duration.

Reward (needed later, not for collecting)

Weighted p-norm, p=0.5, weights [1, 0.3, 0, 0, 0.02, 0.02] on |achieved − desired|, then negated. Collision adds −5. Success if that proximity reward > −0.12.

Variants

parking-v0 empty lot. parking-parked-v0 adds 10 parked cars. Stay empty until MPC works.
