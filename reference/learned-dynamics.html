Cheat sheet

Learned dynamics

Phase 2: an MLP that predicts next kinematics, trained on mixed random + true-env CEM parks, judged by error vs horizon.

Contract

s  = observation  (6,)   x, y, vx, vy, cos_h, sin_h  (scaled)
a  = action       (2,)   acceleration, steering      in [-1, 1]
s' = next observation
f(s, a) → s'             MSE, same scaled space as the npz

Nagabandi often predicts the delta s′ − s then adds. This repo starts with absolute s′. Switch to delta only if one-step MSE stalls.

Identity baseline

Value on random_parking.npz
Predicts′ = s (ignore a)
Overall MSE≈ 0.0033 (stored coordinates)
Largest termsvx, vy (~0.008)
Successes0 / 91 finished episodes

A trained f must beat this on held-out one-step preds. Beating it on crash data only is not parking.

Open-loop rollout

ŝ ← s_t
for h in 1..H:
    ŝ ← f(ŝ, a_{t+h-1})     # feed prediction back; do not reset to truth
    error(h) = ||ŝ − s_{t+h}||²

Plot mean error at H = 1, 2, 5, 10, 20. That is Nagabandi eq. (3) and the PLAN.md diagnostic.

Save executed (s, a, s′) only. Imagined CEM prefixes are not training rows.

Parking CEM rewind

Copy and restore: ego position, heading, speed, action, crashed, hit, impact, every road.objects crash flag, and sim.time / sim.steps. Missing the counters desyncs _simulate (action applied when steps % 3 == 0).

Do not

  • Train f on random-only and call Phase 2 done.
  • Decode pixels or add a JEPA encoder (Phase 4).
  • Use identity MSE in meters against a model trained in scaled units.
  • Score CEM with imagined transitions written into the npz.

Sources: Nagabandi et al. 2018, Hansen et al., TD-MPC2 (planning only), Sutton & Barto §8.1.
